### SiteCommons mobile registrations

The Android application ID and iOS bundle identifier are both `in.thekada.sitecommons`.
Place the matching Firebase files at `android/app/google-services.json` and
`ios/Runner/GoogleService-Info.plist` before building either native target.
Native Firebase reads those files at startup. Flutter web keeps its existing
web configuration. Use a release signing key and record its ownership before
uploading an Android bundle to the new listing.
